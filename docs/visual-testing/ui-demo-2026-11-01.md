# SwarmSync walkthrough recording

Recorded 1 November 2026 using the ui-demo skill. Source: `2471a922b4e1988afe5ef907b4bdb629693af296`; working-tree additions are recording scripts, captures, results and this evidence/TODO update only. No product source changes.

## Reproduce

From `apps/web`, run `npm run dev -- --port 3100`. From the repository root:

```powershell
node docs/visual-testing/demo-discover.cjs
node docs/visual-testing/demo-walkthrough.cjs --rehearse
node docs/visual-testing/demo-walkthrough.cjs
```

Requires externally installed `playwright`, Chromium and its video encoder; these were already available on this machine. The recording uses an isolated browser context and creates its own demo. `QA_BASE_URL` overrides the recording/rehearsal URL. Discovery uses localhost:3100.

## Discovery and rehearsal evidence

Actual headless Chromium at 1280×720, default zoom. [Field map](demo-field-map.json) records visible controls; there are no text inputs or dropdowns in the initial viewer. [Discovery capture](demo-discovery-1280x720.png) inspected for overlap and readable content. Six device cards extend below the viewport; the script scrolls to the live event log.

Rehearsal passed: Play advances time; Pause holds time across a one-second observation; Step advances time; 2× is selected; agent selection opens the inspector; event selection opens the inspector; Reset returns time to zero and clears events. [Machine-readable rehearsal result](demo-rehearse-result.json). Inspector controls were discovered during rehearsal and saved separately. [Inspector capture](demo-inspector-rehearse-1280x720.png) inspected; missing payload values remain dashes.

The first rehearsal exposed an automation timing failure: checking `aria-pressed` immediately after the speed request observed the previous value. Expected: check after the command finishes. Actual: the harness checked while the request was pending. Added a command-completion wait to the shared click helper and reran the same scenario successfully. This was a harness synchronization failure, not a reproduced product defect; no product regression test is claimed.
